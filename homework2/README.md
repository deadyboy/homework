## Requirements Covered

This submission implements the two required parts of Assignment 2:

1. **Poisson Image Editing** in `run_blending_gradio.py`
   - `create_mask_from_points()` converts clicked polygon vertices into a binary mask.
   - `cal_laplacian_loss()` computes the masked Laplacian loss with PyTorch convolution.
2. **Pix2Pix with a Fully Convolutional Network** in `FCN_network.py`
   - A U-Net style encoder-decoder is implemented with skip connections.
   - `train.py` trains with L1 loss and saves train/validation visualizations.

## Part 1: Poisson Image Editing

### Implementation

The polygon mask is rasterized with `PIL.ImageDraw.polygon()` into a single-channel image where the selected region is 255 and the background is 0.

The Poisson objective uses the standard 4-neighbor Laplacian kernel:

```text
[0,  1, 0]
[1, -4, 1]
[0,  1, 0]
```

For each RGB channel, the script computes the Laplacian response of the foreground and current blended image, then minimizes the masked squared difference with Adam. The Gradio UI keeps the background fixed outside the target mask.

### Run

```bash
python run_blending_gradio.py
```

Open the local Gradio URL, upload one foreground and one background image from `data_poisson/`, draw a polygon on the foreground, close it, adjust the target offset, and click **Blend Images**.

## Part 2: Pix2Pix with FCN

### Implementation

`FullyConvNetwork` is a five-level U-Net style fully convolutional model:

| Stage | Channels | Resolution |
|---|---:|---:|
| Input | 3 | 256 x 256 |
| Encoder | 64, 128, 256, 512, 1024 | down to 8 x 8 |
| Decoder | 512, 256, 128, 64, 3 | up to 256 x 256 |

Skip connections concatenate decoder features with the corresponding encoder features. The output uses `Tanh`, matching the dataset normalization to `[-1, 1]`.

`train.py` supports portable paths and command-line options:

```bash
bash download_facades_dataset.sh facades
python train.py --epochs 300 --batch-size 8 --val-batch-size 8
```

The larger reported run used the `edges2shoes` lists already included in this directory:

```bash
python train.py --train-list train_list2.txt --val-list val_list2.txt --epochs 300
```
